# MATERRA — The Living Material Studio

A working full-stack sustainability platform for adaptive circular design intelligence.

**Tagline:** Build from what already exists.

## Built With

`React` `TypeScript` `FastAPI` `Python` `Tailwind CSS` `Vite` `Zustand` `Framer Motion` `Greedy Algorithm` `Real-time Optimization`

## Quick Start

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on http://localhost:3000

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Backend runs on http://localhost:8000

## Architecture

- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend:** Python + FastAPI + Google OR-Tools
- **State:** Zustand (browser localStorage)
- **Optimization:** Real cutting-layout solver with damage-aware regeneration
