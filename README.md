## 🚀 Local Setup (5 Minutes)

**Prerequisites:** Node.js 16+, Python 3.9+

```bash
# Clone
git clone https://github.com/Ananya6Daitkar/GREEN.git
cd GREEN

# Backend (Terminal 1)
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py

# Frontend (Terminal 2)
cd frontend
npm install
npm run dev

# Open: http://localhost:3001
```
