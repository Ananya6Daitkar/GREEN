## 🎬 Animation Examples

### Fade-In Animation
```
Opacity: 0% → 100%
Duration: 600ms
Easing: ease-out
Used on: Page loads, component reveals
```

### Slide-Up Animation
```
Transform: translateY(20px) → translateY(0)
Opacity: 0% → 100%
Duration: 600ms
Easing: ease-out
Used on: Content sections, results display
```

### Component Placement Animation
```
When optimization completes:
- Components fade in one by one
- Utilization % counter animates
- Results panel slides from right
Duration: 400ms per component
```
