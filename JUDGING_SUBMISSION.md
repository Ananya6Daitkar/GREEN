**Setup:**
```bash
# Clone repo
git clone https://github.com/Ananya6Daitkar/GREEN.git

# Terminal 1: Backend
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py

# Terminal 2: Frontend (new terminal)
cd frontend
npm install
npm run dev

# Open browser: http://localhost:3001
```
